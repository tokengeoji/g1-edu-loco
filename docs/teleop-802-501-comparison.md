# G1 텔레옵 정면 출발 비교 · FSM 802와 501

2026년 11월 26일, 운영자는 같은 G1에서 FSM 802로는 양발을 나란히 둔 정면 출발이 어려웠고, FSM 501을 선택한 뒤에는 키보드로 정면 출발했다고 보고했다. 순정 조종기와 내비게이션에서는 보행이 정상이었다. **이번 기체에서 확인된 운용 결과는 501에서 전진이 됐다는 것이다.** 501의 첫발 시각, 관절 목표와 실측, 보폭을 함께 저장한 기록은 없어 두 모드의 내부 보행 알고리즘 차이까지 규명할 수는 없다.

## 802에서 정면과 선회의 차이

11월 23일 2차 실험에서는 첫 요청 직전 0.4초의 다리 자세가 비슷했다. W1–W4에서 다리 12개 관절 각각의 실측 중앙값 차이는 최대 0.018°였다. 아래 두 구간은 당시의 `SetVelocity` 경로를 사용했고 둘 다 횡속도가 0이었다. 각도는 구간 내 최대값과 최소값의 차이이며, 거리는 기체 오도메트리의 시작 방위 기준 추정치다. [실험 구간과 원본 파일 설명](teleop-802-evidence.md)

| FSM 802에서 관측한 입력 | 기체의 보행 상태 | 다리 목표각 최대 변화 | 오른쪽 무릎 실측 변화 | 전방 변위 |
| --- | --- | ---: | ---: | ---: |
| W2 · 정면 전진 +0.15 m/s | 정적 9/9 표본 | 0.77° | 0.0093° | 0 cm |
| W4 · 전진 +0.15 m/s, 우회전 −0.30 rad/s | 첫 요청 26 ms 뒤 동적 표본 관측 | 49.94° | 24.69° | +8.4 cm |

정면과 선회는 같은 속도 API 7105로 전달됐지만 기체가 생성한 다리 목표각부터 달랐다. 운영자는 11월 26일 802에서 두 발이 나란하면 상체만 기울고, 한 발이 앞에 있으면 전후진이 되는 경우도 관찰했다. 전진 +0.30 m/s의 유효시간을 1초에서 2초로 늘린 임시 시험에서도 정면 출발 문제는 남았다. 2초 요청 자체는 격리한 모의 수신기로 검증했다. 802의 첫발 개시 조건과 501에서 정면 출발이 가능해진 정확한 이유는 공개 SDK와 이 기록만으로 특정할 수 없다. [Unitree C++ 속도 API](https://github.com/unitreerobotics/unitree_sdk2/blob/aaf69cb56c9d5ed63d8b284008ec3a8ab999bec1/include/unitree/robot/g1/loco/g1_loco_client.hpp#L164-L173)

## 허리 잠금과 3자유도 옵션

802에서는 기존에도 `--waist-3dof`를 생략해도 됐다. 모의 클라이언트에서 옵션 유무 모두 `i`가 같은 `Move(0.30, 0, 0)`을 호출했다. 옵션은 텔레옵에서 501을 선택하거나 501 상태에서 속도를 보내는 것을 허용하던 장치였다. 앱의 허리 모터 잠금을 바꾸는 명령은 없었다. 11월 23일 W4에서 허리 3축의 실측 변화폭은 요 2.90°, 롤 4.81°, 피치 2.42°였다. 11월 26일 운영자는 앱 잠금 해제를 확인했고, 기체의 `mode_machine=5`는 제조사 표의 허리 3축·29자유도 모델에 해당한다. 과거 앱 잠금 설정이나 물리 고정구의 장착 이력은 기록하지 않았다. [이전 옵션 처리 코드](https://github.com/tokengeoji/g1-edu-loco/blob/b5b164facb941aa277b597018864ce7195bb2df5/src/g1_teleop/control.py#L172-L179) · [Unitree 기체 모델표](https://github.com/unitreerobotics/unitree_ros/blob/157ff950351e5f535e03c5d85a16b7d594b3dbcc/robots/g1_description/README.md)

## 현재 501 선택 방법

**컨테이너 내부**에서 기본 텔레옵을 실행한다.

```bash
g1 teleop --live --interface eth0 --domain 0
```

허리 3자유도 기체에서 물리 고정구가 제거돼 있고 Explore 앱의 허리 모터 잠금이 해제돼 있는지 확인한다. `8`로 501을 선택하고 `Enter`로 전환을 요청한다. `f`에 실제 FSM 501이 표시되고 기체가 안정적으로 서 있을 때 이동 키를 사용한다. 이미 501이면 새 세션에서도 바로 현재 모드를 사용한다. 기존 실행 명령에 붙였던 `--waist-3dof`도 호환된다.
